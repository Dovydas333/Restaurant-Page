Taste House — Luxury Restaurant Website

A responsive, multi-page website built for **Taste House**. 

Designed with a sleek dark aesthetic and gold accents (`#D4A017`) to give off a modern, premium feel.


🚀 Live Demo

👉 [View Live Website](https://dovydas333.github.io/Restaurant-Page/)


🛠️ Built With

HTML5— Semantic markup, accessibility labels, and lazy loading for images.
CSS3 — Custom styling using CSS Grid, Flexbox, blur filters, smooth scrolling, and mobile media queries.
JavaScript — Hamburger menu toggle for modern mobile responsiveness.


✨ Features

Multi-Page Layout:** Includes Home, Menu, About Us, Contact, and Table Reservation pages.
Dark & Gold Aesthetic:** Uses custom typography (Poppins) paired with dark transparent backdrops and gold highlights.
Fully Responsive:** Custom mobile navigation bar with dynamic hamburger animation.
Interactive UI:** Smooth hover transitions on navigation links, cards, buttons, and form controls.
Booking & Contact Forms:** Form layouts with custom styled date and time picker elements.


📸 Screenshots & Highlights

Hero & Navigation:** Sticky glassmorphic navbar (`backdrop-filter`) with smooth hover effects.
Menu Section:** Clean cards for premium dishes like *Classic Ribeye Steak*, *Red Asian Beef Gourmet*, and *Sushi Italian Fusion*.
Mobile First Elements:** Smooth collapsible menu for screens under 900px.
